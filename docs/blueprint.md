# **App Name**: OmniCart

## Core Features:

- Product Catalog & Search: Intuitive browsing through a diverse product catalog with advanced search and filtering capabilities.
- Shopping Cart Management: Comprehensive cart management, allowing users to add, remove, and update product quantities.
- Secure Multi-Option Checkout: A streamlined and secure checkout process integrating various local and international payment systems.
- Vendor Product Listing: A dedicated dashboard interface for vendors to easily add, edit, and manage their product listings.
- Vendor Order Management: Vendors can view and manage their incoming orders, update order statuses, and handle fulfillment.
- AI Product Description Tool: A generative AI tool for vendors to quickly create engaging and detailed product descriptions based on key features.

## Style Guidelines:

- Clean and spacious white (#FFFFFF), as explicitly requested by the user, for primary interactive elements and overall page background.
- A vibrant yet light yellow (#EBDC6D) for calls-to-action, active states, and key branding elements, reflecting the user's request for 'light yellow for accents'.
- A soft, warm gray (#E1E2E3) used for subtle interactive cues, complementary elements, and occasional highlights.
- 'Inter' (sans-serif) for a modern, objective, and clean aesthetic, suitable for both display and extended readability.
- Utilize a consistent set of clean, minimalist line icons to maintain a modern and intuitive user interface.
- Adopt a responsive, grid-based layout for efficient display of product listings and structured information across various devices. Emphasize ample whitespace around elements to ensure a clean look.
- Employ soft light gray (#E1E2E3) for structural components like card backgrounds and subtle borders, adhering to the 'dominant light gray' concept. Very light beige (#F0EEEC) for secondary background variations and subtle highlights.
